# 📊 Laboratory Performance Dashboard (Microsoft Excel)

## 📌 Project Overview
This project presents an interactive Microsoft Excel dashboard developed to analyze a laboratory performance using over 1,000 laboratory records.

The dashboard enables users to monitor key performance indicators (KPIs), evaluate laboratory efficiency, and identify operational improvement opportuninties through interactive filtering and visualization.

## 🎯 Objectives
1. Analyze laboratory workload.
2. Monitor Turnaround Time (TAT).
3. Evaluate revenue performance.
4. Identify sample rejection trends.
5. Compare branch performance.
6. Monitor customer satisfaction.
7. Support data-driven decision-making.

## 🛠️ Tools Used
1. Microsoft Excel.
2. PivotTables.
3. PivotCharts.
4. Slicers.
5. Excel Functions.
6. Dashboard Design.

## 🧹 Data Cleaning
The dataset was cleaned by:
1. Removing duplicate records.
2. Standardizing text values.
3. Validating dates and times.
4. Checking Test-Specimen compatibility.
5. Checking Test-Department compatibility.
6. Identifying gender-test mismatches.
7. Validating turnaround time.
8. Documenting issues in a Data Cleaning Log and Validation Summary.

## 📈 Dashboard Features
1. Interactive KPI Cards.
2. Revenue by Test Type.
3. Revenue by Branch.
4. Samples by Department.
5. Samples by Test Type.
6. TAT Status Distribution
7. Payment Method Distrbution.
8. Sample Rejection Reasons
9. Interactive Slicers.

## 💡 Key Insights
1. The laboratory processed 1,000 samples during the analysis period.
2. Microbiology handled the highest number of samples.
3. Over 80% of samples exceeded the expected turnarond time, indicating workflow improvement opportunities.
4. The laboratory recorded a 7.1% sample rejection rate.
5. Customer satisfaction averaged 2.9/5.
6. Revenue varied across both test types and laboratory branches.
